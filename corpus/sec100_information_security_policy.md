# Harbor Point Bank Information Security Policy

Policy ID: SEC-100
Effective date: 1 January 2025
Owner: Chief Information Security Officer

## 1. Passwords and Authentication

Passwords must be at least 14 characters. Multifactor authentication is required for all remote access and for every system that holds customer data.

## 2. Phishing Reporting

Suspected phishing emails must be reported with the Report Phish button within 1 hour of receipt.

## 3. Data Classification

Data is classified as Public, Internal, Confidential or Restricted. Restricted data may not be stored on personal devices or in unapproved cloud services.

## 4. Incident Reporting

Security incidents must be reported to the Security Operations Center within 30 minutes of discovery.
